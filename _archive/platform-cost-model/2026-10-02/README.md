# Archived platform cost methodology

Snapshot before the 2 October 2026 textual revision to combined offshore EPCI
mass scaling. This archive is excluded from Quarto rendering and publication.

Preserves both methodology pages, their calculation modules, the workflow and
the complete scalar-input table as found in the working tree. The workflow also
contains pre-existing pressure-screen work; this is a snapshot, not a new model
release. Source bibliography remains in the repository's references.bib.

The archived approach separately estimated structural fabrication, yard
integration and offshore installation. These files are reference material, not
an independent executable package. The live calculation modules are unchanged
by this text-only revision and still implement the previous approach. Replacing
the active cost ledger with one EPCI package is a subsequent implementation step.
