# Whole-site review

## Information architecture

- Does navigation follow a logical model or reader dependency order?
- Does every section overview state its role and contents?
- Are pages located under the correct section?
- Are prerequisite and downstream links sufficient?
- Is contextual material clearly separated from model documentation?

## Model coverage

- Does every physical and economic function have one canonical owner?
- Are any functions missing from the architecture component map?
- Are cost, loss, availability and installation boundaries complete?
- Are common assumptions owned once and reused consistently?
- Are the architectures treated on symmetric system boundaries?

## Reader paths

Test whether a new reader can answer:

1. What is being compared and why?
2. What are the model outputs and boundaries?
3. Which components belong to each architecture?
4. Where does each input originate?
5. How does each calculation feed the next one?
6. Which results remain blocked and why?
