## Executive assessment

The page explains the proposed ladder topology clearly and correctly separates
geometric length from hydraulic capacity. The reference arithmetic reproduces:
134 turbines, a 14.142 km square side, 192.0 km for the continuous proxy and
198.0 km for twelve complete rungs.

That proxy is not yet a buildable network. The upstream layout page already
produces rectangular, rotated turbine coordinates and explicitly requires
infield models to consume them. This page instead constructs an independent
square farm and smooth `sqrt(N)` rung count. It consequently does not return
the actual sections, turbine connections, header segment loads, valves,
manifold or physical supply allowances required by cost and installation.

## 3. Calculation reconstruction

The documented proxy is:

1. set `s = sqrt(A_farm)` for a square farm;
2. estimate `n_rung = sqrt(N_turb)` or use `ceil(sqrt(N_turb))`;
3. set every rung and both headers equal to `s`; and
4. sum `L = s(n_rung + 2)`.

The continuous version is dimensionally correct but cannot represent a
physical asset count. The integer version preserves one row-count jump, but
still does not map the actual rectangular coordinate grid into sections. A
minimum implementation needs a section table containing endpoints, length,
connected turbines, healthy and fault-state flow, selected product class,
connections and installation class.

### Boundary and limiting-case checks

- `N_turb = 1` needs an explicit topology rather than two full headers and one
  farm-width rung.
- Non-square and incomplete-row layouts must use their actual dimensions and
  coordinates.
- Every turbine must connect exactly once to a rung while the topology provides
  only the redundancy that the valve and capacity design can support.
- Header flow must accumulate rung flows in the healthy state and be
  recalculated for each claimed fault state.
- Continuous `sqrt(N)` length must not be used to avoid physical row-count and
  connection discontinuities.

## 5. Technical correctness and model fidelity

The stated 500 MW HHV capacity is not a sufficient design check. The current
export-pipeline implementation gives about 437 MW HHV for a 6 inch internal
diameter, 150-to-66 bar, 80 km case; infield capacity will differ because each
section has a different length, outlet pressure and accumulated flow. The page
correctly warns that headers cannot remain 6 inch by assumption, but does not
provide the replacement calculation.

A coordinate-based ladder with segment hydraulics is the minimum sufficient
fidelity. A full hydraulic-network transient model is not yet justified. The
screening model can enumerate deterministic healthy and selected isolation
states, calculate steady segment flows, and reject any unqualified section.

## 6. Cost and evidence audit

The page contains no direct cost. All material and installation cost depends on
the omitted physical inventory. The internal document supports the origin of
the ladder and continuous proxy but is not independent evidence that the
topology, 6 inch pipe or redundancy claim is technically feasible.

The optional route factor has no adopted base value or evidence. This is
preferable to silently inserting the AC-cable 20% factor, but it means routed
length remains unresolved rather than zero by default.

## 7. Independent-implementer test

- **Can the page be implemented?** Only the published length proxy.
- **Missing decisions:** exact topology, manifold boundary, normal/fault states
  and whether redundancy is an objective or only a qualitative feature.
- **Missing equations:** section flow accumulation and pressure/capacity checks.
- **Missing rules:** coordinate mapping, incomplete rows, valve placement,
  section product selection and infeasibility.
- **Missing quantities:** risers, tie-ins, slack, routed deviations and
  connector/manifold counts.

## 8. Explanation and site placement

The explanation is direct and the limitations are unusually visible. The page
is in the right section. Its main editorial problem is status: the headline
length looks like a model result even though the physical and hydraulic
network is not closed. The future correction should present the analytical
formula as a comparator/check, not as the adopted physical inventory.
