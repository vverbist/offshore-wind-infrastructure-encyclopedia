# Page-review notes

Create one detailed note per reviewed page using
`../templates/page-review-template.md`.

Use the page ID as the filename, for example:

- `ELEC-002.md`
- `H2P-003.md`
- `INST-003.md`

These notes preserve reasoning, source checks and calculation reconstruction.
Every actionable finding in a note must also have an issue ID in
`../issue-register.csv`. Use relative links from the note to the reviewed source
page and quote only the minimum source text needed to locate a finding.
